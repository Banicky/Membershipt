## What is this?
This app aims to help users track their subscriptions and recurring bills. It also lets users connect with each other so they can set up a subscription sharing plan.

## Plans
- On the dashboard, add a toggle-able view that shows the final calculated monthly + annual spending and
active + shared plans to account for changes when users decide to utilize the split & share feature
- Allow users to set a billing date start time and auto calculate next billing date based on the billing
cycle (make sure to account for free trials as well)
- Send email to users when nearing a subscription deadline (users can enable or disable this feature)
